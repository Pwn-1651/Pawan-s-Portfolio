# Pawan Singh — Portfolio

A responsive, single-page portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

No build tools, package installation or backend are required.

## Files
- `index.html` — page content and metadata
- `style.css` — responsive visual system and layout
- `script.js` — mobile navigation, current year and back-to-top control

## Design system
- Jet Black: `#0B0B0C`
- Smoke Gray: `#8A8D93`
- White: `#F5F5F3`
- Cherry Red: `#C8102E`

## Before publishing
- Review the contact email and phone number in the page.
- Add a professional headshot if desired (the current hero uses a typographic monogram).
- Confirm the exact GitHub repository links and project descriptions.
- Consider adding a downloadable, updated resume PDF.
- Deploy the extracted folder to GitHub Pages, Netlify, Vercel or your hosting provider.

## Content notes
This portfolio uses information from the supplied resume/profile PDFs and publicly visible GitHub/LinkedIn profile content. The supplied profile lists 6 months of data analytics experience in its summary but does not identify a separate employer/title for that work, so the page labels it as a profile-stated duration rather than inventing a job entry. The supplied resume and LinkedIn PDF differ on some education/contact details; the latest LinkedIn profile PDF details were used for the primary contact and education entries.
